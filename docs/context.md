# Текущий контекст

## Цель

Подготовить основу, из которой пользователь начинает разработку своего продукта с AI-агентом и постоянной памятью.
Конкретный продукт, его аудитория и стек ещё не выбраны.

## Что есть

Ontoship CLI закреплён в `vendor/ontoship/`. Команда `scripts/kb.py` ограничивает поиск и карту папкой `docs/`.
Общий цикл задаёт `AGENTS.md`. Три проектных навыка отвечают за простоту решений, память и понятный технический текст.
Инструкции AGENTS.md и тексты трёх навыков написаны на английском; ответы пользователю по умолчанию — на русском.
Сценарий первого запуска находится в корневом README.

## Проверки

```sh
python -S -m unittest discover -s tests -v
python -S scripts/kb.py lint --strict
python -S scripts/kb.py map
```

Это проверки шаблона. Они не проверяют будущий продукт.
CI настроен на Windows и Linux. Само наличие workflow не означает, что удалённый CI уже запущен.
Фактические результаты текущей подготовки записываются в [журнал](log.md).

## Следующий шаг

Получить первую задачу продукта с наблюдаемым критерием готовности.
Обновить этот контекст: продукт, аудитория, ограничения, принятый стек и реальные команды проверки.
Затем реализовать одну рабочую часть и зафиксировать новые знания.

## Ограничения

Навык технического упрощения по умолчанию использует адаптацию принципов ASD-STE100.
Полного официального словаря в репозитории нет. Соответствие стандарту автоматически не проверяется.
Память обновляется агентом в ходе работы. Фоновое выполнение и видео не настроены.

Основание: [решение о памяти](decisions/0001-markdown-memory.md), [источники](reference/sources.md).
