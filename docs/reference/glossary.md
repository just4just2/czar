# Термины проекта

| Термин | Значение |
|---|---|
| Память проекта / project memory | Проверенные заметки и решения в `docs/` |
| Источник / source | Оригинальный материал, из которого получено утверждение |
| Индекс / index | Пересоздаваемая поисковая база `.gitmark/index.db` |
| Ontoship | Выбранный проект, предоставляющий CLI GitMark |
| GitMark | CLI Ontoship для индекса, поиска, карты и проверки структуры |
| Решение / decision | Принятый выбор с причиной и условием пересмотра |
| Проверка / check | Выполненное действие с наблюдаемым результатом |
| Practical | Адаптация принципов технического упрощения, без заявления о соответствии ASD-STE100 |
| Strict | Проверка английского текста по официальному стандарту и словарю |

Это словарь Czar. Он не заменяет официальный словарь ASD-STE100.
Добавляйте термины продукта по мере появления. Не меняйте имена API ради стиля текста.

Связи: [рабочий цикл](workflow.md), [источники](sources.md).
