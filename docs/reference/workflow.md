# Рабочий цикл

Правила выполнения находятся в `AGENTS.md`. Здесь показан смысл цикла для пользователя.

| Этап | Результат |
|---|---|
| Задача | Нужное поведение и критерий готовности |
| Чтение | Подходящие знания, исходники и ограничения |
| Реализация | Наименьшее законченное изменение |
| Проверка | Наблюдаемое подтверждение поведения либо описанная ошибка |
| Память | Обновлённые факты, решения и следующий шаг |
| Объяснение | Понятный результат с границами проверки |

Пример задачи: «Добавь экспорт записей в CSV. Готово, когда файл содержит выбранные строки,
правильно сохраняет запятые и кириллицу и проверяется запускаемым примером».

Новая сессия начинает с [контекста](../context.md) и [индекса](../README.md).
Для нового источника агент сначала ищет существующую тему, затем уточняет заметку и связи.
Для противоречащих источников агент оставляет обе версии до проверки.
После задачи журнал содержит только значимое изменение знания, а Git — полный diff файлов.

## Выбор объяснения

Текст подходит для короткого результата. Таблица помогает сравнить варианты.
Схема помогает увидеть связи. HTML полезен, если пользователь должен менять параметры и наблюдать результат.
Видео с озвучкой создаётся как отдельная задача; шаблон не устанавливает TTS и не расходует внешние API автоматически.
